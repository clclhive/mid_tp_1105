# 데이터 디렉토리 (Data Directory)

이 디렉토리는 프로젝트에서 사용하는 데이터 파일을 저장합니다.

## 디렉토리 구조 (Directory Structure)

- **raw/**: 원본 공공데이터 파일
- **processed/**: 전처리된 데이터 파일
- **sample/**: 샘플 데이터 파일 (버전 관리에 포함)

## 주의사항 (Notes)

- 대용량 데이터 파일(.csv, .xlsx 등)은 .gitignore에 포함되어 있습니다.
- 샘플 데이터만 Git 저장소에 포함됩니다.
- 실제 데이터는 로컬에서만 관리하거나 별도의 스토리지를 사용하세요.
