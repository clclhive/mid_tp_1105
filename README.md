### 프로젝트 소개 (Project Overview)

### 프로젝트 구조 (Project Structure)
```
mid_tp_1105/
├── src/              # 소스 코드 (Source code)
├── data/             # 데이터 파일 (Data files)
│   ├── raw/          # 원본 데이터 (Raw data)
│   ├── processed/    # 가공 데이터 (Processed data)
│   └── sample/       # 샘플 데이터 (Sample data)
├── notebooks/        # Jupyter 노트북 (Jupyter notebooks)
├── docs/             # 문서 (Documentation)
├── tests/            # 테스트 코드 (Test code)
└── requirements.txt  # 의존성 (Dependencies)
```

### 설치 방법 (Installation)
```bash
# 가상환경 생성 (Create virtual environment)
python -m venv venv

# 가상환경 활성화 (Activate virtual environment)
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

# 의존성 설치 (Install dependencies)
pip install -r requirements.txt
```
